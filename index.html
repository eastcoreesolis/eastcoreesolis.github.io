FEATURED PROJECT

Micah32 / Durable Skills

C# .NET Ollama Docker AI Agents

An experimental agent platform exploring durable AI workflows, local inference, dynamic skill execution, and containerized capabilities.

Micah32 receives problems, classifies them using a local language model, selects appropriate capabilities, and executes work through durable workflows. Skills are isolated as containerized components, allowing the system to expand its capabilities without tightly coupling every tool to the core application.
